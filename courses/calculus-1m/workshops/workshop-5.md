### 题目 1
**题目：** 画出函数 $f(x) = \ln|\sin x|$ 的图像。

<details>
<summary>参考答案</summary>

**解：**

**定义域：** $\sin x \neq 0 \implies x \neq k\pi$，$k \in \mathbb{Z}$。

**周期性：** $f(x + \pi) = \ln|\sin(x+\pi)| = \ln|-\sin x| = \ln|\sin x| = f(x)$，周期为 $\pi$。

**对称性：** $f(-x) = \ln|\sin(-x)| = \ln|-\sin x| = \ln|\sin x| = f(x)$，偶函数。

只需分析 $(0, \pi)$ 上的行为：

- 当 $x \to 0^+$ 时，$\sin x \to 0^+$，$f(x) \to -\infty$（垂直渐近线 $x = 0$）
- 当 $x \to \pi^-$ 时，$\sin x \to 0^+$，$f(x) \to -\infty$（垂直渐近线 $x = \pi$）
- 在 $x = \dfrac{\pi}{2}$ 处，$f\left(\dfrac{\pi}{2}\right) = \ln 1 = 0$（最大值）

**导数：** $f'(x) = \dfrac{\cos x}{\sin x} = \cot x$

- $f'(x) = 0 \implies \cos x = 0 \implies x = \dfrac{\pi}{2}$
- $f'(x) > 0$ 当 $x \in (0, \pi/2)$（递增）
- $f'(x) < 0$ 当 $x \in (\pi/2, \pi)$（递减）

**二阶导数：** $f''(x) = -\csc^2 x < 0$，函数在整个定义域上是**凹的**（concave down）。

**图像描述：** 在每个区间 $(k\pi, (k+1)\pi)$ 上，函数从 $-\infty$ 上升到最大值 0（在中点处），再下降到 $-\infty$，形状像一系列倒置的"钟形"曲线。

**知识点：** 含绝对值的对数函数分析；周期函数的图像只需分析一个周期。

</details>

### 题目 2
**题目：** （2024年春季期末B卷）求 $f(x) = x^4 - 64\ln\left(\dfrac{x}{6}\right)$ 在 $[1, 6]$ 上的全局极值。

提示：$\ln 2 = 0.693\ldots$，$\ln 3 = 1.098\ldots$

<details>
<summary>参考答案</summary>

**解：**

**求临界点：**

$$f'(x) = 4x^3 - 64 \cdot \frac{1}{x/6} \cdot \frac{1}{6} = 4x^3 - \frac{64}{x}$$

令 $f'(x) = 0$：

$$4x^3 = \frac{64}{x} \implies 4x^4 = 64 \implies x^4 = 16 \implies x = 2 \quad (\text{在 } [1,6] \text{ 内})$$

**比较端点和临界点的函数值：**

$f(1) = 1 - 64\ln\left(\dfrac{1}{6}\right) = 1 + 64\ln 6 = 1 + 64(\ln 2 + \ln 3) = 1 + 64(0.693 + 1.098) = 1 + 64(1.791) = 1 + 114.624 = 115.624$

$f(2) = 16 - 64\ln\left(\dfrac{2}{6}\right) = 16 - 64\ln\left(\dfrac{1}{3}\right) = 16 + 64\ln 3 = 16 + 64(1.098) = 16 + 70.272 = 86.272$

$f(6) = 6^4 - 64\ln 1 = 1296 - 0 = 1296$

**全局极值：**

- 全局最小值：$f(2) = 16 + 64\ln 3 \approx 86.27$
- 全局最大值：$f(6) = 1296$

**知识点：** 闭区间上连续函数的全局极值一定在临界点或端点处取得。

</details>

### 题目 3
**题目：** （2021年期末A卷）设 $f: [a, b] \to \mathbb{R}$ 是连续函数，在 $(a, b)$ 上二次可导。假设存在 $c \in (a, b)$ 使得 $f(a) = f(c) = f(b)$。证明至少存在一点 $\alpha \in (a, b)$ 使得 $f'(\alpha) = 0$。

<details>
<summary>参考答案</summary>

**证明：**

由条件 $f(a) = f(c) = f(b)$，其中 $a < c < b$。

**第一步：** 在区间 $[a, c]$ 上应用罗尔定理。

$f$ 在 $[a, c]$ 上连续，在 $(a, c)$ 上可导，且 $f(a) = f(c)$。

由罗尔定理，存在 $\alpha_1 \in (a, c)$ 使得 $f'(\alpha_1) = 0$。

**第二步：** 在区间 $[c, b]$ 上应用罗尔定理。

$f$ 在 $[c, b]$ 上连续，在 $(c, b)$ 上可导，且 $f(c) = f(b)$。

由罗尔定理，存在 $\alpha_2 \in (c, b)$ 使得 $f'(\alpha_2) = 0$。

取 $\alpha = \alpha_1$（或 $\alpha_2$），则 $\alpha \in (a, b)$ 且 $f'(\alpha) = 0$。$\blacksquare$

**注：** 实际上本题证明了至少存在**两个**点使 $f' = 0$。

**知识点：** 罗尔定理：若 $f$ 在 $[a,b]$ 上连续、$(a,b)$ 上可导且 $f(a)=f(b)$，则存在 $c \in (a,b)$ 使 $f'(c)=0$。

</details>

### 题目 4
**题目：** （2022年9月期末A卷）求极限 $\lim_{x \to 0} \dfrac{x^{2x}}{2^x - 1}$。

<details>
<summary>参考答案</summary>

**解：**

首先分析分子 $x^{2x}$ 当 $x \to 0^+$ 时的行为（注意 $x^{2x}$ 仅在 $x > 0$ 时有定义）：

$$x^{2x} = e^{2x \ln x}$$

当 $x \to 0^+$ 时，$x \ln x \to 0$（因为 $\ln x \to -\infty$ 但 $x \to 0$ 更快），所以 $e^{2x \ln x} \to e^0 = 1$。

分母：$2^x - 1 \to 0$（当 $x \to 0$）。

所以这是 $\dfrac{1}{0}$ 型，极限为 $\pm\infty$。

更精确地，当 $x \to 0^+$ 时：

$$2^x - 1 = e^{x \ln 2} - 1 \sim x \ln 2$$

$$\frac{x^{2x}}{2^x - 1} \sim \frac{1}{x \ln 2} \to +\infty$$

$$\boxed{\lim_{x \to 0^+} \frac{x^{2x}}{2^x - 1} = +\infty}$$

**知识点：** $0^0$ 型不定式通过取对数化为 $0 \cdot \infty$ 型；$e^u - 1 \sim u$（$u \to 0$）。

</details>

### 题目 5
**题目：** （2022年9月期末）考虑函数 $f(x) = \dfrac{x^2 - 49}{x^2 + 5x - 14}$。求：

(a) 定义域和对称性

(b) 渐近线

(c) 临界点

(d) 局部极大值和极小值

(e) 递增/递减区间

(f) 拐点

(g) 凹凸区间

(h) 画出图像

<details>
<summary>参考答案</summary>

**(a) 定义域和对称性：**

分母 $x^2 + 5x - 14 = (x+7)(x-2) = 0 \implies x = -7$ 或 $x = 2$。

$$\text{Dom}(f) = \mathbb{R} \setminus \{-7, 2\}$$

化简：$f(x) = \dfrac{(x-7)(x+7)}{(x+7)(x-2)} = \dfrac{x-7}{x-2}$（$x \neq -7$）

$f(-x) = \dfrac{-x-7}{-x-2} = \dfrac{x+7}{x+2} \neq f(x)$ 且 $\neq -f(x)$，**无对称性**。

**(b) 渐近线：**

- 垂直渐近线：$x = 2$（化简后分母为零）；$x = -7$ 是可去间断点（非渐近线）
- 水平渐近线：$\lim_{x \to \pm\infty} \dfrac{x-7}{x-2} = 1$，所以 $y = 1$

**(c) 临界点：**

$$f'(x) = \frac{(x-2) - (x-7)}{(x-2)^2} = \frac{5}{(x-2)^2}$$

$f'(x) > 0$ 对所有 $x \neq 2$ 成立，$f'(x)$ 永不为零。

**无临界点。**

**(d) 局部极值：** 无（$f'$ 永不为零且不变号）。

**(e) 递增/递减区间：**

$f'(x) > 0$ 对所有 $x \in \text{Dom}(f)$ 成立。

$f$ 在 $(-\infty, -7)$、$(-7, 2)$、$(2, +\infty)$ 上分别递增。

**(f) 拐点：**

$$f''(x) = \frac{-10}{(x-2)^3}$$

$f''(x) = 0$ 无解，**无拐点**。

**(g) 凹凸区间：**

- $f''(x) > 0$ 当 $x < 2$：在 $(-\infty, -7)$ 和 $(-7, 2)$ 上凹（concave up）
- $f''(x) < 0$ 当 $x > 2$：在 $(2, +\infty)$ 上凸（concave down）

**(h) 图像描述：**

- 可去间断点 $(-7, \frac{-14}{-9}) = (-7, \frac{14}{9})$（空心点）
- 垂直渐近线 $x = 2$
- 水平渐近线 $y = 1$
- $x$ 截距：$f(x) = 0 \implies x = 7$，即 $(7, 0)$
- $y$ 截距：$f(0) = \dfrac{7}{2}$，即 $(0, 3.5)$
- 函数在各段上递增，$x < 2$ 时凹向上，$x > 2$ 时凹向下

**知识点：** 有理函数分析的标准流程：化简、找渐近线、求导分析单调性和凹凸性。

</details>

### 题目 6
**题目：** （2021年期末A卷）考虑 $f: \mathbb{R} \to \mathbb{R}$，$f(x) = e^x(ax^2 + b)$，其中 $a, b \in \mathbb{R}$。

(a) $f$ 至少有两个临界点的条件是什么？

(b) 设 $a = 4$，$b = 3$。求 $f$ 的递增/递减区间和局部极值点。

<details>
<summary>参考答案</summary>

**(a) 解：**

$$f'(x) = e^x(ax^2 + b) + e^x(2ax) = e^x(ax^2 + 2ax + b)$$

因为 $e^x > 0$，临界点由 $ax^2 + 2ax + b = 0$ 决定。

这是关于 $x$ 的二次方程（当 $a \neq 0$ 时），判别式：

$$\Delta = (2a)^2 - 4ab = 4a^2 - 4ab = 4a(a - b)$$

有两个不同实根的条件：$\Delta > 0 \implies 4a(a-b) > 0$。

- 若 $a > 0$：需要 $a - b > 0 \implies b < a$
- 若 $a < 0$：需要 $a - b < 0 \implies b > a$

综合：$a(a - b) > 0$，即 $a \neq 0$ 且 $b \neq a$ 且 $a$ 与 $a-b$ 同号。

若 $a = 0$：$f'(x) = e^x \cdot b$，当 $b = 0$ 时处处为零（无穷多临界点），当 $b \neq 0$ 时无临界点。

**条件：** $a \neq 0$ 且 $a(a - b) > 0$。

**(b) 解：** $a = 4, b = 3$：

$$f'(x) = e^x(4x^2 + 8x + 3) = e^x(2x + 1)(2x + 3)$$

临界点：$x = -\dfrac{1}{2}$ 和 $x = -\dfrac{3}{2}$。

符号分析：
- $x < -\dfrac{3}{2}$：$(2x+1)(2x+3) > 0 \implies f' > 0$（递增）
- $-\dfrac{3}{2} < x < -\dfrac{1}{2}$：$(2x+1)(2x+3) < 0 \implies f' < 0$（递减）
- $x > -\dfrac{1}{2}$：$(2x+1)(2x+3) > 0 \implies f' > 0$（递增）

**局部极大值：** $x = -\dfrac{3}{2}$，$f\left(-\dfrac{3}{2}\right) = e^{-3/2}(4 \cdot \dfrac{9}{4} + 3) = 12e^{-3/2}$

**局部极小值：** $x = -\dfrac{1}{2}$，$f\left(-\dfrac{1}{2}\right) = e^{-1/2}(4 \cdot \dfrac{1}{4} + 3) = 4e^{-1/2}$

**递增区间：** $\left(-\infty, -\dfrac{3}{2}\right) \cup \left(-\dfrac{1}{2}, +\infty\right)$

**递减区间：** $\left(-\dfrac{3}{2}, -\dfrac{1}{2}\right)$

**知识点：** 含参函数的临界点分析需要讨论参数范围；$e^x$ 因子不影响临界点位置。

</details>

## 📝 本次知识点总结

本次 Workshop 涵盖了函数图像分析与极值问题的核心方法：

1. **函数图像绘制流程**：定义域 → 对称性/周期性 → 渐近线 → 一阶导数（单调性、极值）→ 二阶导数（凹凸性、拐点）→ 关键点 → 绘图。
2. **闭区间全局极值**：比较所有临界点和端点的函数值。
3. **罗尔定理**：$f(a) = f(b)$ 且 $f$ 满足条件时，$(a,b)$ 内必有 $f' = 0$ 的点。
4. **不定型极限**：$0^0$ 型通过取对数处理；$e^u - 1 \sim u$ 是常用等价无穷小。
5. **有理函数分析**：先化简（约去公因子），再系统分析。
6. **含参函数**：临界点个数由判别式决定，需分类讨论参数。
