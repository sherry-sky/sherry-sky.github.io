### 题目 1
**题目：** 求解下列不等式：

(a) $|x - 3| < 4$

(b) $\dfrac{1}{2x - 3} \geq 2$

<details>
<summary>参考答案</summary>

**(a) 解：**

由绝对值不等式的性质 $|x - a| < b \iff a - b < x < a + b$：

$$|x - 3| < 4 \iff -4 < x - 3 < 4 \iff -1 < x < 7$$

所以解集为 $x \in (-1, 7)$。

**(b) 解：**

首先注意 $2x - 3 \neq 0$，即 $x \neq \dfrac{3}{2}$。

$$\frac{1}{2x - 3} \geq 2$$

分两种情况讨论：

**情况 1：** $2x - 3 > 0$，即 $x > \dfrac{3}{2}$。此时两边乘以 $2x - 3$ 不改变不等号方向：

$$1 \geq 2(2x - 3) = 4x - 6 \implies 7 \geq 4x \implies x \leq \frac{7}{4}$$

结合 $x > \dfrac{3}{2}$，得 $\dfrac{3}{2} < x \leq \dfrac{7}{4}$。

**情况 2：** $2x - 3 < 0$，即 $x < \dfrac{3}{2}$。此时两边乘以 $2x - 3$ 改变不等号方向：

$$1 \leq 4x - 6 \implies x \geq \frac{7}{4}$$

但 $\dfrac{7}{4} > \dfrac{3}{2}$，与 $x < \dfrac{3}{2}$ 矛盾，无解。

综上，解集为 $x \in \left(\dfrac{3}{2}, \dfrac{7}{4}\right]$。

**知识点：** 绝对值不等式的基本性质；分式不等式需分母正负讨论。

</details>

### 题目 2
**题目：** 证明：若 $|x + 3| < \dfrac{1}{2}$，则 $|4x + 13| < 13$。

<details>
<summary>参考答案</summary>

**解：**

由 $|x + 3| < \dfrac{1}{2}$，可得：

$$-\frac{1}{2} < x + 3 < \frac{1}{2} \implies -\frac{7}{2} < x < -\frac{5}{2}$$

因此：

$$4x \in (-14, -10) \implies 4x + 13 \in (-1, 3)$$

所以 $|4x + 13| < 3 < 13$。

**另一种方法（三角不等式）：**

$$|4x + 13| = |4(x + 3) + 1| \leq |4(x+3)| + |1| = 4|x+3| + 1 < 4 \cdot \frac{1}{2} + 1 = 3 < 13$$

**知识点：** 三角不等式 $|a + b| \leq |a| + |b|$ 的应用。

</details>

### 题目 3
**题目：** 求过点 $P$ 和 $Q$ 的直线斜率：

(a) $P = (1, 5)$，$Q = (4, 11)$

(b) $P = (-1, 6)$，$Q = (4, -3)$

(c) $P = (-3, 3)$，$Q = (-1, -6)$

<details>
<summary>参考答案</summary>

**解：** 斜率公式 $m = \dfrac{y_2 - y_1}{x_2 - x_1}$。

**(a)** $m = \dfrac{11 - 5}{4 - 1} = \dfrac{6}{3} = 2$

**(b)** $m = \dfrac{-3 - 6}{4 - (-1)} = \dfrac{-9}{5} = -\dfrac{9}{5}$

**(c)** $m = \dfrac{-6 - 3}{-1 - (-3)} = \dfrac{-9}{2} = -\dfrac{9}{2}$

**知识点：** 两点间斜率公式 $m = \dfrac{\Delta y}{\Delta x}$。

</details>

### 题目 4
**题目：** 证明直线 $2x - y = 4$ 和 $6x - 2y = 10$ 不平行，并求它们的交点。

<details>
<summary>参考答案</summary>

**解：**

将两直线化为斜截式：

- $2x - y = 4 \implies y = 2x - 4$，斜率 $m_1 = 2$
- $6x - 2y = 10 \implies y = 3x - 5$，斜率 $m_2 = 3$

因为 $m_1 = 2 \neq 3 = m_2$，所以两直线不平行。

求交点：令 $2x - 4 = 3x - 5$，得 $x = 1$，代入得 $y = 2(1) - 4 = -2$。

交点为 $(1, -2)$。

**知识点：** 两直线平行当且仅当斜率相等；求交点即联立方程组求解。

</details>

### 题目 5
**题目：** 证明直线 $3x - 5y + 19 = 0$ 和 $10x + 6y - 50 = 0$ 互相垂直，并求它们的交点。

<details>
<summary>参考答案</summary>

**解：**

化为斜截式：

- $3x - 5y + 19 = 0 \implies y = \dfrac{3}{5}x + \dfrac{19}{5}$，斜率 $m_1 = \dfrac{3}{5}$
- $10x + 6y - 50 = 0 \implies y = -\dfrac{5}{3}x + \dfrac{25}{3}$，斜率 $m_2 = -\dfrac{5}{3}$

因为 $m_1 \cdot m_2 = \dfrac{3}{5} \cdot \left(-\dfrac{5}{3}\right) = -1$，所以两直线互相垂直。

求交点：联立

$$\frac{3}{5}x + \frac{19}{5} = -\frac{5}{3}x + \frac{25}{3}$$

两边乘以 15：

$$9x + 57 = -25x + 125 \implies 34x = 68 \implies x = 2$$

代入 $y = \dfrac{3}{5}(2) + \dfrac{19}{5} = \dfrac{25}{5} = 5$。

交点为 $(2, 5)$。

**知识点：** 两直线垂直当且仅当斜率之积为 $-1$。

</details>

### 题目 6
**题目：** 证明下列方程表示圆，并求圆心和半径：

(a) $x^2 + y^2 - 4x + 10y + 13 = 0$

(b) $2x^2 + 2y^2 - x + y = 1$

<details>
<summary>参考答案</summary>

**(a) 解：** 对 $x$ 和 $y$ 分别配方：

$$x^2 - 4x + y^2 + 10y = -13$$

$$(x^2 - 4x + 4) + (y^2 + 10y + 25) = -13 + 4 + 25 = 16$$

$$(x - 2)^2 + (y + 5)^2 = 16 = 4^2$$

圆心为 $(2, -5)$，半径为 $4$。

**(b) 解：** 先除以 2：

$$x^2 + y^2 - \frac{1}{2}x + \frac{1}{2}y = \frac{1}{2}$$

配方：

$$\left(x^2 - \frac{1}{2}x + \frac{1}{16}\right) + \left(y^2 + \frac{1}{2}y + \frac{1}{16}\right) = \frac{1}{2} + \frac{1}{16} + \frac{1}{16} = \frac{10}{16} = \frac{5}{8}$$

$$\left(x - \frac{1}{4}\right)^2 + \left(y + \frac{1}{4}\right)^2 = \frac{5}{8}$$

圆心为 $\left(\dfrac{1}{4}, -\dfrac{1}{4}\right)$，半径为 $\sqrt{\dfrac{5}{8}} = \dfrac{\sqrt{10}}{4}$。

**知识点：** 圆的一般方程 $x^2 + y^2 + Dx + Ey + F = 0$ 通过配方可化为标准形式 $(x-a)^2 + (y-b)^2 = r^2$。

</details>

### 题目 7
**题目：** 方程 $x^2 + y^2 + 2ax + 2by + c = 0$ 在系数 $a, b, c$ 满足什么条件时表示一个圆？当条件满足时，求圆心和半径。

<details>
<summary>参考答案</summary>

**解：** 配方：

$$(x^2 + 2ax + a^2) + (y^2 + 2by + b^2) = a^2 + b^2 - c$$

$$(x + a)^2 + (y + b)^2 = a^2 + b^2 - c$$

该方程表示一个圆当且仅当右边为正数，即：

$$a^2 + b^2 - c > 0 \iff c < a^2 + b^2$$

此时圆心为 $(-a, -b)$，半径为 $r = \sqrt{a^2 + b^2 - c}$。

**知识点：** 圆的一般方程表示圆的充要条件是 $D^2 + E^2 - 4F > 0$（对应本题即 $4a^2 + 4b^2 - 4c > 0$）。

</details>

### 题目 8
**题目：** 画出由 $y = 3x$ 和 $y = x^2$ 围成的区域。

<details>
<summary>参考答案</summary>

**解：**

首先求交点：$3x = x^2 \implies x^2 - 3x = 0 \implies x(x-3) = 0$，所以 $x = 0$ 或 $x = 3$。

交点为 $(0, 0)$ 和 $(3, 9)$。

在区间 $(0, 3)$ 上，$3x > x^2$（例如 $x=1$ 时 $3 > 1$），所以直线 $y = 3x$ 在抛物线 $y = x^2$ 上方。

围成的区域是：在 $x \in [0, 3]$ 范围内，$x^2 \leq y \leq 3x$ 的部分。

草图描述：
- 抛物线 $y = x^2$ 开口向上，过原点
- 直线 $y = 3x$ 过原点，斜率为 3
- 两曲线在原点和 $(3, 9)$ 处相交
- 围成的区域呈"月牙形"，在两条曲线之间

**知识点：** 求曲线围成区域需先找交点，再判断上下关系。

</details>

### 题目 9
**题目：** 画出 $x^2 - y^2 - 4x + 3 = 0$ 的图像。

<details>
<summary>参考答案</summary>

**解：** 对 $x$ 配方：

$$x^2 - 4x + 4 - y^2 = -3 + 4 = 1$$

$$(x - 2)^2 - y^2 = 1$$

这是标准双曲线方程 $\dfrac{(x-2)^2}{1} - \dfrac{y^2}{1} = 1$。

- 中心在 $(2, 0)$
- 实轴沿 $x$ 方向，$a = 1$
- 虚轴 $b = 1$
- 顶点在 $(2 \pm 1, 0) = (1, 0)$ 和 $(3, 0)$
- 渐近线：$y = \pm(x - 2)$

草图描述：双曲线开口向左和向右，中心在 $(2, 0)$，两支分别经过 $(1, 0)$ 和 $(3, 0)$。

**知识点：** 双曲线标准形式 $\dfrac{(x-h)^2}{a^2} - \dfrac{(y-k)^2}{b^2} = 1$，中心 $(h,k)$，渐近线 $y - k = \pm \dfrac{b}{a}(x - h)$。

</details>

## 📝 本次知识点总结

本次 Workshop 涵盖了微积分预备知识中的核心内容：

1. **绝对值不等式**：掌握 $|x-a| < b$ 的解法，以及利用三角不等式进行证明。
2. **直线方程**：斜率公式、平行（斜率相等）与垂直（斜率之积为 $-1$）的判定、交点求解。
3. **圆的方程**：一般式与标准式的互化，配方法是关键技巧。
4. **圆锥曲线**：通过配方识别双曲线，确定中心、顶点、渐近线等要素。
5. **区域绘制**：求交点、判断上下关系是画区域的基本步骤。
