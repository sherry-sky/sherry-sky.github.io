# Week 24: 幂级数

## 📌 知识点概述

本周深入学习幂级数的概念、收敛半径与收敛区间的求法，以及将函数表示为幂级数的方法。重点掌握利用几何级数、逐项求导、逐项积分等技巧将函数展开为幂级数，并理解幂级数的收敛性质。

## 📖 核心内容

### 定义

**幂级数**：

$$f(x) = \sum_{n=0}^{\infty} c_n (x - x_0)^n$$

其中 $c_n$ 为系数，$x_0$ 为中心点。

**收敛半径 $R$**：幂级数 $\sum c_n(x-a)^n$ 有且仅有三种情况：
1. 仅在 $x = a$ 处收敛（$R = 0$）
2. 对所有 $x \in \mathbb{R}$ 收敛（$R = \infty$）
3. 存在 $R > 0$，$|x - a| < R$ 时收敛，$|x - a| > R$ 时发散

**收敛区间**：可以是 $(a-R, a+R)$、$[a-R, a+R)$、$(a-R, a+R]$ 或 $[a-R, a+R]$。端点需单独判断。

### 定理

**定理 1（幂级数的逐项运算）**：若 $\sum c_n(x-a)^n$ 的收敛半径为 $R > 0$，则在 $(a-R, a+R)$ 内：

1. **逐项求导**：$f'(x) = \sum_{n=1}^{\infty} n c_n (x-a)^{n-1}$

2. **逐项积分**：$\int f(x)\,dx = C + \sum_{n=0}^{\infty} \frac{c_n}{n+1}(x-a)^{n+1}$

3. 运算后级数的收敛半径仍为 $R$（端点敛散性可能改变）。

**定理 2（幂级数收敛性质）**：若 $\sum c_n(x-a)^n$ 的收敛半径为 $R > 0$，则：
1. 级数在 $(a-R, a+R)$ 内绝对收敛
2. 级数在 $(-\infty, a-R) \cup (a+R, +\infty)$ 上发散

**推论**：若 $\sum c_n(x-a)^n$ 在 $x_0$ 处收敛，则对所有满足 $|x - a| < |x_0 - a|$ 的 $x$，级数绝对收敛。

### 重要公式

**几何级数**：

$$\frac{1}{1-r} = \sum_{n=0}^{\infty} r^n \quad (|r| < 1)$$

**常用函数展开**：

$$\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n \quad (-1 < x < 1)$$

$$\frac{1}{(1-x)^2} = \sum_{n=0}^{\infty} (n+1)x^n \quad (-1 < x < 1)$$

$$\ln(1+x) = \sum_{k=1}^{\infty} \frac{(-1)^{k-1}}{k} x^k \quad (-1 < x \leq 1]$$

$$\arctan x = \sum_{n=0}^{\infty} \frac{(-1)^n}{2n+1} x^{2n+1} \quad |x| < 1$$

### 典型例题

**例 1.** 求幂级数 $\sum_{n=0}^{\infty} \frac{(2x-5)^n}{\sqrt{n+2}}$ 的收敛区间。

**解.** 用比值判别法：

$$\lim_{n \to \infty} \left|\frac{a_{n+1}}{a_n}\right| = \lim_{n \to \infty} \frac{|2x-5|^{n+1}}{\sqrt{n+3}} \cdot \frac{\sqrt{n+2}}{|2x-5|^n} = |2x-5| \cdot \lim_{n \to \infty} \sqrt{\frac{n+2}{n+3}} = |2x-5|$$

收敛条件：$|2x - 5| < 1$，即 $|x - \frac{5}{2}| < \frac{1}{2}$，收敛半径 $R = \frac{1}{2}$。

区间为 $(2, 3)$。

**端点检验**：
- $x = 3$：$2x - 5 = 1$，$\sum_{n=0}^{\infty} \frac{1}{\sqrt{n+2}}$，$p = \frac{1}{2} \leq 1$，发散。
- $x = 2$：$2x - 5 = -1$，$\sum_{n=0}^{\infty} \frac{(-1)^n}{\sqrt{n+2}}$，由 Leibniz 判别法（$\frac{1}{\sqrt{n+2}}$ 递减趋于 $0$），收敛。

收敛区间为 $[2, 3)$。$\blacksquare$

---

**例 2.** 将 $f(x) = \frac{1}{1-x^2}$ 表示为 $x = 0$ 处的幂级数。

**解.** 利用几何级数，取 $r = x^2$：

$$f(x) = \frac{1}{1-x^2} = \sum_{n=0}^{\infty} (x^2)^n = \sum_{n=0}^{\infty} x^{2n} = 1 + x^2 + x^4 + x^6 + \cdots$$

收敛条件：$|x^2| < 1$，即 $|x| < 1$，收敛区间为 $(-1, 1)$。$\blacksquare$

---

**例 3.** 将 $g(x) = \frac{x}{(1-x^2)^2}$ 表示为幂级数。

**解.** 由例 2 知 $\frac{1}{1-x^2} = \sum_{n=0}^{\infty} x^{2n}$。

注意到 $\frac{d}{dx}\left(\frac{1}{1-x^2}\right) = \frac{2x}{(1-x^2)^2}$，故：

$$\frac{x}{(1-x^2)^2} = \frac{1}{2} \cdot \frac{d}{dx}\left(\frac{1}{1-x^2}\right) = \frac{1}{2} \frac{d}{dx} \sum_{n=0}^{\infty} x^{2n} = \frac{1}{2} \sum_{n=1}^{\infty} 2n \cdot x^{2n-1} = \sum_{n=1}^{\infty} n x^{2n-1}$$

收敛区间为 $(-1, 1)$。$\blacksquare$

---

**例 4.** 求 $\sum_{n=1}^{\infty} \frac{n^2}{2^n}(x-1)^n$ 的收敛区间。

**解.** 用比值判别法：

$$\lim_{n \to \infty} \left|\frac{a_{n+1}}{a_n}\right| = \lim_{n \to \infty} \frac{(n+1)^2}{2^{n+1}} \cdot \frac{2^n}{n^2} \cdot |x-1| = \frac{|x-1|}{2} \lim_{n \to \infty} \left(\frac{n+1}{n}\right)^2 = \frac{|x-1|}{2}$$

收敛条件：$\frac{|x-1|}{2} < 1$，即 $|x - 1| < 2$，$R = 2$。

区间为 $(-1, 3)$。

**端点检验**：
- $x = 3$：$\sum_{n=1}^{\infty} \frac{n^2}{2^n} \cdot 2^n = \sum_{n=1}^{\infty} n^2$，通项趋于 $\infty$，发散。
- $x = -1$：$\sum_{n=1}^{\infty} \frac{n^2}{2^n} \cdot (-2)^n = \sum_{n=1}^{\infty} n^2(-1)^n$，通项不趋于 $0$，发散。

收敛区间为 $(-1, 3)$。$\blacksquare$

---

**例 5.** 将 $f(x) = \frac{1}{x+5}$ 表示为以 $x = -2$ 为中心的幂级数，并求收敛区间。

**解.** 将 $f(x)$ 改写为含 $(x+2)$ 的形式：

$$f(x) = \frac{1}{x+5} = \frac{1}{3 + (x+2)} = \frac{1}{3} \cdot \frac{1}{1 + \frac{x+2}{3}} = \frac{1}{3} \cdot \frac{1}{1 - \left(-\frac{x+2}{3}\right)}$$

利用几何级数 $\frac{1}{1-r} = \sum_{n=0}^{\infty} r^n$，其中 $r = -\frac{x+2}{3}$：

$$f(x) = \frac{1}{3} \sum_{n=0}^{\infty} \left(-\frac{x+2}{3}\right)^n = \sum_{n=0}^{\infty} \frac{(-1)^n}{3^{n+1}} (x+2)^n$$

收敛条件：$\left|\frac{x+2}{3}\right| < 1$，即 $|x + 2| < 3$，$R = 3$。

**端点检验**：
- $x = 1$：$\sum_{n=0}^{\infty} \frac{(-1)^n}{3^{n+1}} \cdot 3^n = \sum_{n=0}^{\infty} \frac{(-1)^n}{3}$，通项不趋于 $0$，发散。
- $x = -5$：$\sum_{n=0}^{\infty} \frac{(-1)^n}{3^{n+1}} \cdot (-3)^n = \sum_{n=0}^{\infty} \frac{1}{3}$，通项不趋于 $0$，发散。

收敛区间为 $(-5, 1)$。$\blacksquare$

## 📝 本周知识点总结

1. 幂级数的收敛半径 $R$ 通常用**比值判别法**或**根值判别法**求得
2. 收敛区间的**端点必须单独检验**，可能收敛也可能发散
3. 将函数展开为幂级数的核心方法：
   - **几何级数法**：将函数化为 $\frac{1}{1-r}$ 的形式
   - **逐项求导**：由已知级数求导得到新级数
   - **逐项积分**：由已知级数积分得到新级数
   - **代入/复合**：将 $x$ 替换为其他表达式
4. 逐项求导和积分不改变收敛半径，但端点敛散性可能改变
5. 幂级数在其收敛区间内表示的函数是连续且可导的
6. 换元技巧：将 $x - a$ 视为整体，利用已知展开式
