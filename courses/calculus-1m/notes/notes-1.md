# Week 1: 预备知识——不等式、绝对值、坐标几何与三角学

## 📌 知识点概述

本周是微积分 1M 课程的预备知识周，主要回顾和巩固以下基础内容：不等式的求解与区间表示、绝对值的性质与不等式、中点公式与坐标几何、直线方程（平行与垂直）、平面区域的描绘，以及三角函数的基本性质与方程求解。

## 📖 核心内容

### 定义

**区间表示法：** 设 $a < b$ 为实数，常用区间如下：

| 区间 | 集合表示 | 名称 |
|------|----------|------|
| $(a, b)$ | $\{x \mid a < x < b\}$ | 开区间 |
| $[a, b]$ | $\{x \mid a \leq x \leq b\}$ | 闭区间 |
| $(a, +\infty)$ | $\{x \mid x > a\}$ | 无穷区间 |

**绝对值：** 对任意实数 $a$，
$$|a| = \begin{cases} a, & a \geq 0 \\ -a, & a < 0 \end{cases}$$

**绝对值不等式：** 设 $c > 0$，
- $|x| \leq c \iff -c \leq x \leq c$
- $|x| \geq c \iff x \leq -c$ 或 $x \geq c$

### 定理

**中点公式：** 若 $x < y$，则 $x < \dfrac{x+y}{2} < y$。

**直线方程：**
- 过点 $(x_0, y_0)$、斜率为 $m$ 的直线：$y - y_0 = m(x - x_0)$
- 平行线斜率相同；垂直线斜率互为负倒数（$m_1 \cdot m_2 = -1$）

### 重要公式

**三角恒等式：**
$$\sin^2\theta + \cos^2\theta = 1$$
$$1 + \tan^2\theta = \sec^2\theta$$
$$1 + \cot^2\theta = \csc^2\theta$$

**特殊角的三角函数值：** $\sin\dfrac{\pi}{6} = \dfrac{1}{2}$，$\cos\dfrac{\pi}{3} = \dfrac{1}{2}$，$\cos\dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2}$

### 典型例题

**例 1.** 解不等式 $x(x - 4) \geq -2$，并用区间表示解集。

**解.** 将不等式化为标准形式：
$$x^2 - 4x + 2 \geq 0$$
求根公式：$x = \dfrac{4 \pm \sqrt{16 - 8}}{2} = \dfrac{4 \pm 2\sqrt{2}}{2} = 2 \pm \sqrt{2}$

因为二次项系数为正，抛物线开口向上，所以不等式在两根之外成立：
$$x \in (-\infty, 2 - \sqrt{2}] \cup [2 + \sqrt{2}, +\infty)$$

---

**例 2.** 解不等式 $\dfrac{1}{25} \leq \dfrac{1}{x^2 - 6x + 9}$。

**解.** 注意 $x^2 - 6x + 9 = (x-3)^2$，所以不等式为：
$$\frac{1}{25} \leq \frac{1}{(x-3)^2}$$
因为 $(x-3)^2 > 0$（$x \neq 3$），两边取倒数（注意不等号方向反转）：
$$(x-3)^2 \leq 25$$
$$|x - 3| \leq 5 \implies -5 \leq x - 3 \leq 5 \implies -2 \leq x \leq 8$$
又因为 $x \neq 3$，所以解集为：
$$x \in [-2, 3) \cup (3, 8]$$

---

**例 3.** 求过点 $(1, 2)$ 且平行于 $y = 3x + 5$ 的直线方程。

**解.** 平行线斜率相同，$m = 3$。由点斜式：
$$y - 2 = 3(x - 1) \implies y = 3x - 1$$

---

**例 4.** 求过点 $(-3, 0)$ 且垂直于 $y = -4x + 1$ 的直线方程。

**解.** 垂直线斜率互为负倒数：$m = \dfrac{1}{4}$。由点斜式：
$$y - 0 = \frac{1}{4}(x + 3) \implies y = \frac{1}{4}x + \frac{3}{4}$$

---

**例 5.** 设 $\sin\theta = \dfrac{3}{2}$ 不成立（因为 $|\sin\theta| \leq 1$），改为：设 $\sin\theta = \dfrac{\sqrt{3}}{2}$ 且 $\cos\theta > 0$，求 $\theta$ 的其他三角函数值。

**解.** 由 $\sin\theta = \dfrac{\sqrt{3}}{2}$ 且 $\cos\theta > 0$，知 $\theta$ 在第一象限：
$$\cos\theta = \sqrt{1 - \sin^2\theta} = \sqrt{1 - \frac{3}{4}} = \sqrt{\frac{1}{4}} = \frac{1}{2}$$
$$\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{\sqrt{3}/2}{1/2} = \sqrt{3}$$
$$\cot\theta = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}, \quad \sec\theta = 2, \quad \csc\theta = \frac{2\sqrt{3}}{3}$$

## 📝 本周知识点总结

1. **不等式求解**：通过因式分解或求根公式找到零点，再利用符号分析确定解集区间。
2. **绝对值不等式**：利用 $|x| \leq c$ 和 $|x| \geq c$ 的基本形式转化。
3. **直线方程**：掌握点斜式，理解平行与垂直的斜率关系。
4. **坐标几何**：能在平面上描绘由不等式定义的区域，理解圆、抛物线等基本曲线。
5. **三角学**：熟练运用三角恒等式，能根据已知条件求出所有三角函数值。
