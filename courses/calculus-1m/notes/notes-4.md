# Week 4: 连续性与导数入门

## 📌 知识点概述

本周学习两个核心主题：（1）函数的连续性——包括连续性的定义、间断点的分类、连续函数的性质，以及无穷远处的极限和渐近线；（2）导数的初步概念——从切线问题和瞬时速度引入导数的定义，学习基本函数的导数公式和切线方程。

## 📖 核心内容

### 定义

**连续性：** 函数 $f$ 在 $x = a$ 处连续，当且仅当：
1. $f(a)$ 有定义
2. $\lim_{x \to a} f(x)$ 存在
3. $\lim_{x \to a} f(x) = f(a)$

**间断点分类：**
- **可去间断点**：$\lim_{x \to a} f(x)$ 存在但 $\neq f(a)$（或 $f(a)$ 无定义）
- **跳跃间断点**：左右极限都存在但不相等
- **无穷间断点**：$\lim_{x \to a} f(x) = \pm\infty$

**导数：** 函数 $f$ 在 $x = a$ 处的导数定义为：
$$f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h} = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

**切线方程：** 曲线 $y = f(x)$ 在点 $(a, f(a))$ 处的切线方程为：
$$y = f(a) + f'(a)(x - a)$$

### 定理

**可导必连续：** 若 $f$ 在 $x = a$ 处可导，则 $f$ 在 $x = a$ 处连续。反之不成立（如 $f(x) = |x|$ 在 $x = 0$ 处连续但不可导）。

**不可导的三种几何情形：**
1. **尖角**（corner）：左右导数存在但不相等，如 $f(x) = |x|$ 在 $x = 0$
2. **跳跃间断**：函数不连续
3. **垂直切线**：导数为 $\pm\infty$，如 $f(x) = x^{1/3}$ 在 $x = 0$

### 重要公式

**基本导数公式：**

| $f(x)$ | $f'(x)$ |
|---------|---------|
| $c$ | $0$ |
| $x$ | $1$ |
| $x^n$ | $nx^{n-1}$ |
| $x^r$ | $rx^{r-1}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\dfrac{1}{x}$ |

**导数运算法则：**
- $(f + g)' = f' + g'$
- $(cf)' = cf'$
- $(fg)' = f'g + fg'$（乘法法则）
- $\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$（除法法则）

### 典型例题

**例 1.** 判断 $f(x) = \dfrac{x^2 - 1}{x - 1}$ 在 $x = 1$ 处的连续性。

**解.** $f(1)$ 无定义（分母为零），因此 $f$ 在 $x = 1$ 处不连续。但：
$$\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = \lim_{x \to 1} \frac{(x-1)(x+1)}{x-1} = \lim_{x \to 1} (x+1) = 2$$
极限存在但 $f(1)$ 无定义，因此 $x = 1$ 是**可去间断点**。

---

**例 2.** 求 $f(x) = x^2$ 在点 $(1, 1)$ 和 $(-3, 9)$ 处的切线方程。

**解.** 先求导数：$f'(x) = 2x$。

在 $(1, 1)$ 处：斜率 $m = f'(1) = 2$，切线方程为：
$$y = 1 + 2(x - 1) = 2x - 1$$

在 $(-3, 9)$ 处：斜率 $m = f'(-3) = -6$，切线方程为：
$$y = 9 + (-6)(x + 3) = 9 - 6x - 18 = -6x - 9$$

---

**例 3.** 求 $f(x) = e^x + 2\cos x + 4x^3$ 在点 $(0, 3)$ 处的切线方程。

**解.** 求导数：
$$f'(x) = e^x - 2\sin x + 12x^2$$
在 $x = 0$ 处：$f'(0) = e^0 - 2\sin 0 + 0 = 1$。

切线方程为：
$$y = 3 + 1 \cdot (x - 0) = x + 3$$

---

**例 4.** 求 $f(x) = |x|$ 的导数，并说明 $f$ 在 $x = 0$ 处不可导。

**解.** 对 $x > 0$：$|x| = x$，$f'(x) = 1$。
对 $x < 0$：$|x| = -x$，$f'(x) = -1$。

在 $x = 0$ 处：
$$f'(0) = \lim_{h \to 0} \frac{|0 + h| - |0|}{h} = \lim_{h \to 0} \frac{|h|}{h}$$
- 右极限：$\lim_{h \to 0^+} \dfrac{h}{h} = 1$
- 左极限：$\lim_{h \to 0^-} \dfrac{-h}{h} = -1$

左右极限不相等，极限不存在，因此 $f'(0)$ **不存在**。几何上，$|x|$ 在 $x = 0$ 处有一个尖角。

---

**例 5.** 求 $f(x) = \dfrac{x - 1}{x - 2}$ 的水平渐近线和垂直渐近线。

**解.**
- **垂直渐近线**：分母为零的点 $x = 2$。
  $\lim_{x \to 2^+} f(x) = +\infty$，$\lim_{x \to 2^-} f(x) = -\infty$，所以 $x = 2$ 是垂直渐近线。

- **水平渐近线**：
  $\lim_{x \to \pm\infty} \dfrac{x - 1}{x - 2} = \lim_{x \to \pm\infty} \dfrac{1 - 1/x}{1 - 2/x} = 1$

  所以 $y = 1$ 是水平渐近线。

## 📝 本周知识点总结

1. **连续性**：函数在某点连续需要三个条件同时满足。
2. **间断点**：分为可去间断、跳跃间断和无穷间断。
3. **导数定义**：导数是差商的极限，表示瞬时变化率和切线斜率。
4. **基本导数公式**：掌握幂函数、三角函数、指数函数、对数函数的导数。
5. **求导法则**：和差、常数倍、乘积、商的求导法则。
6. **可导与连续的关系**：可导 $\implies$ 连续，但连续 $\not\implies$ 可导。
7. **渐近线**：垂直渐近线由分母零点产生，水平渐近线由无穷极限决定。
