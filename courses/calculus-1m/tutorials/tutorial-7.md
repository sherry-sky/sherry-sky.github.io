### 题目 1

**题目：** 用单一公式定义函数 $f$，满足：
- 定义域为 $[0, 3) \cup (3, 5) \cup (5, +\infty)$
- $f$ 恰好有一个垂直渐近线和一个水平渐近线
- $f$ 恰好有一个局部极大值（也是全局极大值），一个局部极小值但无全局极小值

<details>
<summary>参考答案</summary>

**解：**

分析：定义域缺少 $x = 3$ 和 $x = 5$，但只要求一个垂直渐近线。设垂直渐近线在 $x = 3$，$x = 5$ 是可去间断点。

构造思路：
- 分母含 $(x - 3)$ 产生垂直渐近线
- 分子含 $(x - 5)$ 使 $x = 5$ 为可去间断点
- 水平渐近线要求 $x \to \infty$ 时趋于常数
- 需要定义域从 $0$ 开始，可用 $\sqrt{x}$ 或限制 $x \geq 0$

一个可能的构造：
$$f(x) = \frac{(x - 5)^2}{(x - 3)} \cdot \frac{1}{x + 1}$$

但需要更精细地调整以满足所有条件。此题为开放性设计题，答案不唯一。

**知识点：** 综合理解定义域、渐近线、极值等概念，将它们整合到一个函数中。

</details>

### 题目 2（核心题）

**题目：** 描绘下列函数的图像。

**(a)** $f(x) = \frac{x^2}{x^2 - 4}$

**(b)** $f(x) = \frac{x^2 - 2x - 3}{x^2 - 2x + 1} + 2$

<details>
<summary>参考答案</summary>

**解：**

**(a)** $f(x) = \frac{x^2}{x^2 - 4} = \frac{x^2}{(x-2)(x+2)}$

- **定义域**：$x \neq \pm 2$
- **对称性**：$f(-x) = f(x)$，偶函数
- **渐近线**：垂直 $x = \pm 2$；水平 $\lim_{x \to \pm\infty} f(x) = 1$，即 $y = 1$
- **$f'(x)$**：$f'(x) = \frac{2x(x^2 - 4) - x^2 \cdot 2x}{(x^2 - 4)^2} = \frac{-8x}{(x^2 - 4)^2}$

$f'(x) = 0 \implies x = 0$，$f(0) = 0$（局部极小值）。

$x < 0$ 时 $f' > 0$（递增），$0 < x < 2$ 时 $f' < 0$（递减）。

- **$f''(x)$**：$f''(0) = \frac{-8(x^2 - 4)^2 + 8x \cdot 2(x^2 - 4) \cdot 2x}{(x^2 - 4)^4}\Big|_{x=0} = \frac{-8 \cdot 16}{256} = -\frac{1}{2} < 0$

$x = 0$ 处凹向下，确认为局部极大值... 等等，让我重新计算。

$f'(x) = \frac{-8x}{(x^2-4)^2}$，$f''(x) = \frac{-8(x^2-4)^2 - (-8x) \cdot 2(x^2-4) \cdot 2x}{(x^2-4)^4} = \frac{-8(x^2-4) + 32x^2}{(x^2-4)^3} = \frac{24x^2 + 32}{(x^2-4)^3}$

$f''(0) = \frac{32}{(-4)^3} = \frac{32}{-64} = -\frac{1}{2} < 0$

$x = 0$ 处凹向下，$f'(0) = 0$，所以 $x = 0$ 是局部**极大**值。$f(0) = 0$。

但 $f(x) = \frac{x^2}{x^2 - 4}$，在 $x = 0$ 附近 $f(x) < 0$（因为 $x^2 - 4 < 0$），$f(0) = 0$ 确实是极大值。

**(b)** $f(x) = \frac{(x-3)(x+1)}{(x-1)^2} + 2 = \frac{x^2 - 2x - 3 + 2(x-1)^2}{(x-1)^2} = \frac{3x^2 - 6x - 1}{(x-1)^2}$

- **定义域**：$x \neq 1$
- **垂直渐近线**：$x = 1$
- **水平渐近线**：$\lim_{x \to \pm\infty} f(x) = 3$，即 $y = 3$

**知识点：** 函数图像描绘需系统分析定义域、对称性、渐近线、单调性、凹凸性。

</details>

### 题目 3

**题目：** 线段 $C = \{(x, y) \in \mathbb{R}^2 : x + y = 1,\; -1 \leq x \leq 0\}$ 上哪个点离 $(1, 3)$ 最近？

<details>
<summary>参考答案</summary>

**解：**

线段上点可表示为 $(x, 1 - x)$，$-1 \leq x \leq 0$。

距离的平方：$D(x) = (x - 1)^2 + (1 - x - 3)^2 = (x - 1)^2 + (x + 2)^2 = x^2 - 2x + 1 + x^2 + 4x + 4 = 2x^2 + 2x + 5$

$D'(x) = 4x + 2 = 0 \implies x = -\frac{1}{2}$

$D(-1) = 2 - 2 + 5 = 5$，$D(-1/2) = \frac{1}{2} - 1 + 5 = \frac{9}{2}$，$D(0) = 5$

$D(-1/2) = 4.5 < 5$，所以最近点为 $x = -\frac{1}{2}$，$y = \frac{3}{2}$。

$$\boxed{\left(-\frac{1}{2},\; \frac{3}{2}\right)}$$

**知识点：** 优化问题——最小化距离的平方（等价于最小化距离）。

</details>

### 题目 4

**题目：** 求过点 $(3, 5)$ 的直线方程，使其在第一象限截出的三角形面积最小。

<details>
<summary>参考答案</summary>

**解：**

设直线斜率为 $k < 0$（必须在第一象限截出三角形）：$y - 5 = k(x - 3)$。

$x$ 截距（$y = 0$）：$x = 3 - \frac{5}{k}$

$y$ 截距（$x = 0$）：$y = 5 - 3k$

面积 $A = \frac{1}{2}\left(3 - \frac{5}{k}\right)(5 - 3k) = \frac{1}{2}\left(15 - 9k - \frac{25}{k} + 15\right) = \frac{1}{2}\left(30 - 9k - \frac{25}{k}\right)$

$A'(k) = \frac{1}{2}\left(-9 + \frac{25}{k^2}\right) = 0 \implies k^2 = \frac{25}{9} \implies k = -\frac{5}{3}$（取负值）

直线方程：$y - 5 = -\frac{5}{3}(x - 3)$，即 $\boxed{y = -\frac{5}{3}x + 10}$，或 $5x + 3y = 30$。

最小面积 $A = \frac{1}{2} \cdot 6 \cdot 10 = 30$。

**知识点：** 优化问题——建立目标函数，求导找极值。

</details>

### 题目 5（核心题）

**题目：** 求下列函数的不定积分。

**(a)** $f(x) = x^3 + (3x)^3$

**(b)** $f(x) = 2\sin x + \cos(3x)$

**(c)** $f(x) = \frac{3x^2}{1 + 9x^3}$

**(d)** $f(x) = \frac{1}{2}e^{-4x} + \cosh x$

**(e)** $f(x) = 8\sec x(\sec x - 4\tan x)$

**(f)** $f(x) = \frac{\tan^2 x}{1 + x^2}$... 注：原题可能为 $\frac{1}{1 + x^2}$ 或类似形式。

<details>
<summary>参考答案</summary>

**解：**

**(a)** $f(x) = x^3 + 27x^3 = 28x^3$

$$\int f(x)\,dx = 28 \cdot \frac{x^4}{4} + C = \boxed{7x^4 + C}$$

**(b)** $\int (2\sin x + \cos 3x)\,dx = -2\cos x + \frac{1}{3}\sin 3x + C$

$$\boxed{-2\cos x + \frac{1}{3}\sin 3x + C}$$

**(c)** 令 $u = 1 + 9x^3$，$du = 27x^2\,dx$：

$$\int \frac{3x^2}{1 + 9x^3}\,dx = \frac{3}{27}\int \frac{du}{u} = \frac{1}{9}\ln|u| + C = \boxed{\frac{1}{9}\ln|1 + 9x^3| + C}$$

**(d)** $\int \left(\frac{1}{2}e^{-4x} + \cosh x\right)\,dx = -\frac{1}{8}e^{-4x} + \sinh x + C$

$$\boxed{-\frac{1}{8}e^{-4x} + \sinh x + C}$$

**(e)** $8\sec x(\sec x - 4\tan x) = 8\sec^2 x - 32\sec x \tan x$

$$\int (8\sec^2 x - 32\sec x \tan x)\,dx = 8\tan x - 32\sec x + C$$

$$\boxed{8\tan x - 32\sec x + C}$$

**知识点：** 基本积分公式，换元积分法。

</details>

### 题目 6

**题目：** 求解初值问题。

**(a)** $f'(x) = x^{-4}$，$f(1) = 1$

**(b)** $f'(x) = 3x^5 - 6x^2 + 15x - 1$，$f(0) = -1$

<details>
<summary>参考答案</summary>

**解：**

**(a)** $f(x) = \int x^{-4}\,dx = -\frac{1}{3}x^{-3} + C$

$f(1) = -\frac{1}{3} + C = 1 \implies C = \frac{4}{3}$

$$\boxed{f(x) = -\frac{1}{3x^3} + \frac{4}{3}}$$

**(b)** $f(x) = \frac{x^6}{2} - 2x^3 + \frac{15x^2}{2} - x + C$

$f(0) = C = -1$

$$\boxed{f(x) = \frac{x^6}{2} - 2x^3 + \frac{15x^2}{2} - x - 1}$$

**知识点：** 先求不定积分（含常数 $C$），再用初值条件确定 $C$。

</details>

### 题目 8（核心题）

**题目：** 用黎曼和求下列定积分。

**(a)** $\int_1^2 x^3\,dx$

**(b)** $\int_0^1 e^x\,dx$

<details>
<summary>参考答案</summary>

**解：**

**(a)** 将 $[1, 2]$ 等分为 $n$ 份，$\Delta x = \frac{1}{n}$，$x_i = 1 + \frac{i}{n}$。

用右端点黎曼和：
$$S_n = \sum_{i=1}^n x_i^3 \Delta x = \frac{1}{n}\sum_{i=1}^n \left(1 + \frac{i}{n}\right)^3$$

展开并利用求和公式（过程略），取极限 $n \to \infty$：

$$\int_1^2 x^3\,dx = \frac{x^4}{4}\Big|_1^2 = \frac{16}{4} - \frac{1}{4} = \boxed{\frac{15}{4}}$$

**(b)** 将 $[0, 1]$ 等分为 $n$ 份，$\Delta x = \frac{1}{n}$，$x_i = \frac{i}{n}$。

$$S_n = \frac{1}{n}\sum_{i=1}^n e^{i/n} = \frac{1}{n} \cdot e^{1/n} \cdot \frac{1 - e}{1 - e^{1/n}} = \frac{e^{1/n}(e - 1)}{n(e^{1/n} - 1)}$$

当 $n \to \infty$ 时，$n(e^{1/n} - 1) \to 1$，$e^{1/n} \to 1$：

$$\int_0^1 e^x\,dx = \boxed{e - 1}$$

**知识点：** 定积分的定义——黎曼和在分割趋于无穷细时的极限。

</details>

### 题目 9

**题目：** 已知 $\int_{-2}^0 f(x)\,dx = 2$，$\int_{-2}^0 g(x)\,dx = -1$，$\int_3^0 f(x)\,dx = -\frac{2}{3}$。计算：

**(a)** $\int_{-2}^0 f(x)\,dx$ **(b)** $\int_{-2}^0 \left(2f(x) + \frac{1}{3}g(x)\right)\,dx$

<details>
<summary>参考答案</summary>

**解：**

**(a)** $\int_{-2}^0 f(x)\,dx = \boxed{2}$（直接已知）

**(b)** 利用积分的线性性：
$$\int_{-2}^0 \left(2f(x) + \frac{1}{3}g(x)\right)\,dx = 2\int_{-2}^0 f(x)\,dx + \frac{1}{3}\int_{-2}^0 g(x)\,dx = 2(2) + \frac{1}{3}(-1) = 4 - \frac{1}{3} = \boxed{\frac{11}{3}}$$

**知识点：** 定积分的线性性质。

</details>

### 题目 10

**题目：** 设 $f(x) = \begin{cases} 1 & x \in \mathbb{Q} \\ 0 & x \notin \mathbb{Q} \end{cases}$（Dirichlet 函数）。证明 $f$ 不可积。

<details>
<summary>参考答案</summary>

**证明：**

对 $[a, b]$ 的任意分割 $P$，每个子区间 $[x_{i-1}, x_i]$ 中既有有理数也有无理数。

上黎曼和：$U(f, P) = \sum_{i=1}^n 1 \cdot \Delta x_i = b - a$

下黎曼和：$L(f, P) = \sum_{i=1}^n 0 \cdot \Delta x_i = 0$

上积分 $\overline{\int} f = b - a \neq 0 = \underline{\int} f$（下积分）。

上下积分不相等，故 $f$ 在 $[a, b]$ 上不可积（Riemann 不可积）。$\blacksquare$

**知识点：** Riemann 可积的充要条件是上下积分相等；Dirichlet 函数是经典的不可积例子。

</details>

## 📝 本次知识点总结

1. **函数图像描绘**：综合运用定义域、渐近线、导数分析来绘制精确图像。
2. **优化问题**：建立目标函数，利用导数求极值，注意定义域的约束。
3. **不定积分**：基本积分公式和换元法是求原函数的基础工具。
4. **初值问题**：先求通解（含 $C$），再代入初值确定常数。
5. **黎曼和**：定积分的严格定义，通过极限计算精确值。
6. **可积性**：Dirichlet 函数展示了 Riemann 积分的局限性。
