### 题目 1

**题目：** 给出满足以下条件的连续函数例子：

**(a)** $f: (a, b] \to \mathbb{R}$ 有上界但无最大值

**(b)** $f: (a, b) \to \mathbb{R}$ 在 3 个点取到最小值

**(c)** $f: [a, +\infty) \to \mathbb{R}$ 无最大值也无最小值

<details>
<summary>参考答案</summary>

**解：**

**(a)** $f(x) = x$ 在 $(0, 1]$ 上——等等，这有最大值 $f(1) = 1$。

改为：$f(x) = -x$ 在 $(0, 1]$ 上。上确界为 $0$（$x \to 0^+$），但取不到。有上界（如 $1$），无最大值。

**(b)** $f(x) = |x|$ 在 $(-2, 2)$ 上只有 1 个最小值点。

构造：在 $(-2, 2)$ 上取 $f(x) = |\sin(3\pi x/2)|$ 等，使最小值在 3 个点取到。

更简单的例子：设 $f$ 在 $(-2, 2)$ 上为分段线性函数，在 $x = -1, 0, 1$ 处取值为 $0$（最小值），在 $x = -0.5, 0.5$ 处取值为 $1$。

**(c)** $f(x) = x$ 在 $[0, +\infty)$ 上：无最大值（$f(x) \to +\infty$），有最小值 $f(0) = 0$。

改为：$f(x) = x \sin x$ 在 $[0, +\infty)$ 上，振幅不断增大，无最大值也无最小值。

或更简单：$f(x) = x + \sin x$，无界且无最小值。

**知识点：** 极值定理要求闭区间上的连续函数才有最大/最小值。开区间或无界区间上可能不成立。

</details>

### 题目 3（核心题）

**题目：** 求临界点并分类，求绝对最大/最小值。

**(a)** $f(x) = |x + 1| - |x - 1|$，$[-4, 2]$

**(b)** $f(x) = x + \sin x$，$[0, 4\pi]$

**(c)** $f(x) = \cos x + \sin x$，$[0, 2\pi]$

**(d)** $f(x) = \sqrt{x} - \sqrt[3]{x}$，$[0, 5]$

**(e)** $f(x) = \frac{x}{x^2 - 1}$，$\mathbb{R}$（去掉 $x = \pm 1$）

**(f)** $f(x) = x^2 e^{-2x}$，$\mathbb{R}$

<details>
<summary>参考答案</summary>

**解：**

**(a)** 分段表示：
- $x < -1$：$f(x) = -(x+1) - (-(x-1)) = -x - 1 + x - 1 = -2$
- $-1 \leq x < 1$：$f(x) = (x+1) - (-(x-1)) = x + 1 + x - 1 = 2x$
- $x \geq 1$：$f(x) = (x+1) - (x-1) = 2$

临界点：$x = -1$ 和 $x = 1$（$f'$ 不存在）。

$f(-4) = -2$，$f(-1) = -2$，$f(1) = 2$，$f(2) = 2$。

绝对最小值 $-2$（在 $[-4, -1]$ 上），绝对最大值 $2$（在 $[1, 2]$ 上）。

**(b)** $f'(x) = 1 + \cos x = 0 \implies \cos x = -1 \implies x = \pi, 3\pi$。

$f'(x) \geq 0$（$f'$ 仅在离散点为零），$f$ 单调递增。

$f(0) = 0$，$f(4\pi) = 4\pi$。

绝对最小值 $0$（$x = 0$），绝对最大值 $4\pi$（$x = 4\pi$）。

临界点 $x = \pi, 3\pi$ 不是极值点（$f$ 在这些点两侧均递增）。

**(c)** $f'(x) = -\sin x + \cos x = 0 \implies \tan x = 1 \implies x = \frac{\pi}{4}, \frac{5\pi}{4}$。

$f(0) = 1$，$f\left(\frac{\pi}{4}\right) = \sqrt{2}$，$f(\pi) = -1$，$f\left(\frac{5\pi}{4}\right) = -\sqrt{2}$，$f(2\pi) = 1$。

绝对最大值 $\sqrt{2}$（$x = \frac{\pi}{4}$），绝对最小值 $-\sqrt{2}$（$x = \frac{5\pi}{4}$）。

**(d)** $f'(x) = \frac{1}{2\sqrt{x}} - \frac{1}{3x^{2/3}} = 0 \implies \frac{1}{2\sqrt{x}} = \frac{1}{3x^{2/3}}$

$3x^{2/3} = 2\sqrt{x} = 2x^{1/2} \implies x^{2/3 - 1/2} = \frac{2}{3} \implies x^{1/6} = \frac{2}{3} \implies x = \left(\frac{2}{3}\right)^6 = \frac{64}{729}$

$f(0) = 0$，$f(5) = \sqrt{5} - \sqrt[3]{5} \approx 2.236 - 1.710 = 0.526$。

$f\left(\frac{64}{729}\right) = \frac{8}{27} - \frac{4}{9} = \frac{8 - 12}{27} = -\frac{4}{27}$

绝对最小值 $-\frac{4}{27}$（$x = \frac{64}{729}$），绝对最大值 $\sqrt{5} - \sqrt[3]{5}$（$x = 5$）。

**(f)** $f'(x) = 2xe^{-2x} + x^2(-2)e^{-2x} = 2xe^{-2x}(1 - x) = 0 \implies x = 0$ 或 $x = 1$。

$f(0) = 0$，$f(1) = e^{-2}$。当 $x \to \pm\infty$ 时 $f(x) \to +\infty$（$x \to -\infty$）或 $f(x) \to 0$（$x \to +\infty$）。

$x = 0$ 为局部最小值，$x = 1$ 为局部最大值 $e^{-2}$。无绝对最大值（$x \to -\infty$ 时 $f \to +\infty$），绝对最小值 $0$（$x = 0$）。

**知识点：** 临界点包括 $f'(x) = 0$ 和 $f'(x)$ 不存在的点；绝对极值需比较临界点和端点的函数值。

</details>

### 题目 4

**题目：**

**(a)** 说明中值定理中连续性条件的必要性。

**(b)** 说明可微性条件的必要性。

**(c)** 若函数有间断点，是否仍可能有 $f'(c)(b - a) = f(b) - f(a)$？

<details>
<summary>参考答案</summary>

**解：**

**(a)** 设 $f(x) = \begin{cases} 0 & x \in [0, 1) \\ 1 & x = 1 \end{cases}$。$f$ 在 $[0, 1]$ 上可微（在 $(0,1)$ 内 $f' = 0$），$f(0) = 0$，$f(1) = 1$。

MVT 要求存在 $c \in (0, 1)$ 使 $f'(c) = \frac{1 - 0}{1 - 0} = 1$，但 $f'(x) = 0$ 对所有 $x \in (0, 1)$，矛盾。

**(b)** 设 $f(x) = |x|$ 在 $[-1, 1]$ 上。$f$ 连续但 $x = 0$ 处不可微。$f'(x) = -1$（$x < 0$）或 $1$（$x > 0$）。

MVT 要求 $f'(c) = \frac{f(1) - f(-1)}{2} = 0$，但 $f'(x) = \pm 1 \neq 0$。

**(c)** 可以。例如 $f(x) = \begin{cases} x^2 & x \neq 0 \\ 1 & x = 0 \end{cases}$ 在 $[-1, 1]$ 上，$f$ 在 $x = 0$ 处有可去间断。

$\frac{f(1) - f(-1)}{2} = 0$，$f'(c) = 2c = 0 \implies c = 0$，但 $f$ 在 $c = 0$ 处不可微。

换一个：设 $f(x) = x^3$ 在 $x \neq 0$，$f(0) = 1$。则 $\frac{f(1) - f(-1)}{2} = 1$，$f'(c) = 3c^2 = 1 \implies c = \frac{1}{\sqrt{3}}$，该点处 $f$ 可微且 $f'(c) = 1$。所以即使有间断点，也可能存在满足条件的 $c$。

**知识点：** MVT 的两个条件（连续、可微）缺一不可，但结论在条件不满足时仍可能偶然成立。

</details>

### 题目 6

**题目：** 设 $f: [0, 2] \to \mathbb{R}$ 连续，$f(0) = 0$，$f(1) = 1$，$f(2) = 4$。证明存在 $c \in (0, 2)$ 使 $f'(c) = d$，$d = 1.5, 2, 2.5$。

<details>
<summary>参考答案</summary>

**证明：**

由 MVT：
- 在 $[0, 1]$ 上：存在 $c_1 \in (0, 1)$ 使 $f'(c_1) = \frac{1 - 0}{1 - 0} = 1$
- 在 $[1, 2]$ 上：存在 $c_2 \in (1, 2)$ 使 $f'(c_2) = \frac{4 - 1}{2 - 1} = 3$

$f'$ 满足达布定理（Darboux 定理，导数的介值定理）：即使 $f'$ 不连续，$f'$ 也取到 $f'(c_1) = 1$ 和 $f'(c_2) = 3$ 之间的所有值。

因此对 $d = 1.5, 2, 2.5 \in (1, 3)$，均存在 $c \in (c_1, c_2) \subset (0, 2)$ 使 $f'(c) = d$。$\blacksquare$

**知识点：** MVT + 达布定理（导函数具有介值性）。

</details>

### 题目 7

**题目：** 证明方程 $x^3 + e^x = 0$ 恰好有一个解。

<details>
<summary>参考答案</summary>

**证明：**

设 $f(x) = x^3 + e^x$。

**存在性：** $f(-1) = -1 + e^{-1} = -1 + 0.368 < 0$，$f(0) = 0 + 1 = 1 > 0$。

由介值定理，存在 $c \in (-1, 0)$ 使 $f(c) = 0$。

**唯一性：** $f'(x) = 3x^2 + e^x > 0$ 对所有 $x$ 成立，故 $f$ 严格递增，至多一个零点。

综合得恰好一个解。$\blacksquare$

**知识点：** 介值定理证存在性，单调性证唯一性。

</details>

### 题目 9（核心题）

**题目：** 对 $f(x) = \sqrt{x^2 - x}$ 和 $g(x) = \frac{2x}{3x^2 + 6x + 3}$，分析以下内容：定义域与对称性、渐近线、临界点、极值、单调性、拐点、凹凸性、绘制图像。

<details>
<summary>参考答案</summary>

**解：**

**$f(x) = \sqrt{x^2 - x} = \sqrt{x(x - 1)}$：**

**(a)** 定义域：$x(x-1) \geq 0 \implies x \leq 0$ 或 $x \geq 1$，即 $(-\infty, 0] \cup [1, +\infty)$。

无对称性。

**(b)** 渐近线：$x \to \pm\infty$ 时 $f(x) \approx |x| = \pm x$。

更精确：$\sqrt{x^2 - x} = |x|\sqrt{1 - 1/x} \approx |x|(1 - \frac{1}{2x}) = |x| - \frac{1}{2}\text{sgn}(x)$

斜渐近线：$y = -x + \frac{1}{2}$（$x \to -\infty$），$y = x - \frac{1}{2}$（$x \to +\infty$）。

**(c)** $f'(x) = \frac{2x - 1}{2\sqrt{x^2 - x}}$。$f'(x) = 0 \implies x = \frac{1}{2}$（不在定义域内）。

$f'(x)$ 在定义域内不为零。在 $x = 0$ 和 $x = 1$ 处 $f'$ 不存在。

**(d)(e)** $x < 0$ 时 $f'(x) = \frac{2x - 1}{2\sqrt{x^2 - x}} < 0$（分子负，分母正），递减。

$x > 1$ 时 $f'(x) > 0$，递增。

$f(0) = 0$ 为局部（绝对）最小值，$f(1) = 0$ 为局部（绝对）最小值。

**$g(x) = \frac{2x}{3x^2 + 6x + 3} = \frac{2x}{3(x + 1)^2}$：**

**(a)** 定义域：$x \neq -1$。无特殊对称性。

**(b)** 水平渐近线：$\lim_{x \to \pm\infty} g(x) = 0$，即 $y = 0$。

垂直渐近线：$x = -1$。

**(c)** $g'(x) = \frac{2 \cdot 3(x+1)^2 - 2x \cdot 6(x+1)}{9(x+1)^4} = \frac{6(x+1) - 12x}{9(x+1)^3} = \frac{6 - 6x}{9(x+1)^3} = \frac{2(1 - x)}{3(x+1)^3}$

$g'(x) = 0 \implies x = 1$。$g(1) = \frac{2}{12} = \frac{1}{6}$。

**(d)(e)** $x < -1$ 时 $g'(x) < 0$（分子正，分母负），递减。

$-1 < x < 1$ 时 $g'(x) > 0$，递增。

$x > 1$ 时 $g'(x) < 0$，递减。

$x = 1$ 为局部最大值 $\frac{1}{6}$。

**知识点：** 函数图像分析的完整流程：定义域 → 渐近线 → 一阶导数（单调性、极值）→ 二阶导数（凹凸性、拐点）。

</details>

### 题目 10（核心题）

**题目：** 求下列极限。

**(a)** $\lim_{x \to \infty} \frac{2x}{x^2 + 2x + 1}$

**(b)** $\lim_{x \to 0^+} \left(\frac{1}{x^2} - \frac{1}{\tan x}\right)$

**(c)** $\lim_{x \to 0^+} x^{\sin x}$

**(d)** $\lim_{x \to \infty} x^{1/x}$

**(e)** $\lim_{x \to \infty} (e^x - x)$

**(f)** $\lim_{x \to 0^+} (1 + \sin 3x)^{1/x}$

**(g)** $\lim_{x \to \infty} \frac{\sqrt{x}}{\sqrt{x^2 + 1}}$

**(h)** $\lim_{x \to \infty} \frac{3x^3 - \sin x}{x^3 + 1}$

<details>
<summary>参考答案</summary>

**解：**

**(a)** $\frac{2x}{x^2 + 2x + 1} = \frac{2/x}{1 + 2/x + 1/x^2} \to \frac{0}{1} = \boxed{0}$

**(b)** $\frac{1}{x^2} - \frac{1}{\tan x} = \frac{\tan x - x^2}{x^2 \tan x}$

当 $x \to 0^+$ 时，$\tan x \approx x$，$\frac{1}{x^2} - \frac{1}{x} = \frac{1 - x}{x^2} \to +\infty$。

$$\boxed{+\infty}$$

**(c)** 令 $y = x^{\sin x}$，$\ln y = \sin x \cdot \ln x$。

$\lim_{x \to 0^+} \sin x \ln x = \lim_{x \to 0^+} \frac{\ln x}{1/\sin x} = \lim_{x \to 0^+} \frac{\ln x}{\csc x}$

L'Hôpital：$= \lim_{x \to 0^+} \frac{1/x}{-\csc x \cot x} = \lim_{x \to 0^+} \frac{-\sin x \tan x}{x} = \lim_{x \to 0^+} \frac{-\sin^2 x}{x \cos x} = 0$

$\ln y \to 0 \implies y \to e^0 = \boxed{1}$

**(d)** $\ln y = \frac{\ln x}{x} \to 0$（L'Hôpital），$y \to e^0 = \boxed{1}$

**(e)** $e^x - x = e^x(1 - xe^{-x}) \to +\infty \cdot 1 = \boxed{+\infty}$

**(f)** $\ln y = \frac{\ln(1 + \sin 3x)}{x}$，L'Hôpital：$= \lim_{x \to 0^+} \frac{3\cos 3x}{1 + \sin 3x} = 3$

$y \to \boxed{e^3}$

**(g)** $\frac{\sqrt{x}}{\sqrt{x^2 + 1}} = \sqrt{\frac{x}{x^2 + 1}} = \sqrt{\frac{1/x}{1 + 1/x^2}} \to \sqrt{0} = \boxed{0}$

**(h)** $\frac{3x^3 - \sin x}{x^3 + 1} = \frac{3 - \sin x / x^3}{1 + 1/x^3} \to \frac{3 - 0}{1 + 0} = \boxed{3}$

**知识点：** 不定型极限的处理方法——L'Hôpital 法则、取对数转化、等价无穷小替换。

</details>

## 📝 本次知识点总结

1. **极值与最值**：临界点（$f' = 0$ 或 $f'$ 不存在）和端点都需比较。
2. **中值定理**：连续 + 可微是必要条件；结合达布定理可证明导函数取中间值。
3. **函数图像分析**：系统化的分析流程是微积分的核心应用。
4. **不定型极限**：$\frac{0}{0}$、$\frac{\infty}{\infty}$、$0 \cdot \infty$、$1^\infty$、$0^0$ 等不定型需转化为可用 L'Hôpital 法则的形式。
