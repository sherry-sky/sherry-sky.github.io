# 答案质量检查技能

## 触发条件

- "检查答案质量" / "验证答案" / "审查解答"
- homework-to-md 生成答案后触发

## 检查维度

### 1. 计算正确性

- [ ] 代数运算、求根公式、积分/导数、三角恒等式正确
- [ ] 数值计算经二次验算，不等式方向正确
- [ ] **使用 SymPy 独立验证关键推导**（见下方验证流程）

### 2. 逻辑完整性

- [ ] 每步有文字说明，不跳步
- [ ] 分类讨论完整（绝对值正负、分母不为零等）
- [ ] 边界条件、定义域限制已考虑
- [ ] 无占位符（如"（计算略）"、"需比较..."）

### 3. 格式规范性

- [ ] 公式用 `$...$` 或 `$$...$$` 包裹
- [ ] 公式末尾无 PDF 自动编号
- [ ] 最终答案用 `\boxed{}`，证明题有 `$\blacksquare$`
- [ ] `_`、`*` 仅在公式内使用
- [ ] 中英文之间有空格

### 4. AI 痕迹清理

- [ ] 删除思考过程：如"等等，让我重新计算"、"Hmm"
- [ ] 删除占位符：如"（需比较...）"、"（计算略）"
- [ ] 补全不完整答案
- [ ] 删除重复推导

**快速定位关键词**：`等等` / `让我重新` / `重新计算` / `这似乎` / `不太对` / `Wait, let me` / `Hmm` / `Actually` / `计算略` / `过程略` / `也许原题` / `让我简化`

### 5. 原始答案对比（如有）

- [ ] 最终答案与 PDF 原始答案一致
- [ ] 如有差异，标注并分析原因

### 6. 特殊情况处理

- [ ] **发散积分**：若题目标注"求精确值"但积分发散，明确说明发散原因并讨论题目可能的印刷错误
- [ ] **"需数值方法"的题目**：用 SymPy 验证是否实际有闭式解（如 HW8 Q4a 的旋转面面积实际 = π/2）
- [ ] **依赖图片的题目**：从原始 PDF 提取图片（见 `pdf-image-extract`），补充完整解答

## 工作流

### 阶段一：批量扫描（快速定位问题）

对课程目录下所有 Markdown 文件执行批量关键词搜索，快速定位疑似问题文件：

```bash
# 搜索 AI 痕迹和不完整答案
grep -l "计算略\|过程略\|此处略\|让我重新\|等等\|这似乎\|不太对\|Wait\|Hmm\|Actually\|也许原题\|让我简化" *.md || echo "无匹配"
```

这可以在逐一阅读前就识别出需要重点关注的文件。

### 阶段二：逐一审查

1. 读取已生成的 Markdown 文件
2. 按上述 6 个维度逐项检查
3. **直接修正发现的问题**（不只是报告）

### 阶段三：输出总结

输出简要修改总结表格：

| 文件 | 质量 | 修改 |
|------|------|------|
| file-1.md | ✅ 良好 | 无 |
| file-2.md | ⚠️ 小问题 | ✅ 修复 XX（补充不完整的积分表达式） |

## SymPy 验证流程

对关键数学推导使用 SymPy 独立验证：

```python
import sympy as sp

# 验证导数
x = sp.Symbol('x')
f = ...  # 原函数
f_prime = sp.diff(f, x)

# 验证积分
result = sp.integrate(f, x)

# 验证化简
expr = sp.simplify(...)

# 验证定积分
val = sp.integrate(f, (x, a, b))

# 验证极限
lim = sp.limit(f, x, point)
```
